# CountCharLine (Sublime Text Plugin)

Um plugin para **Sublime Text 3 e 4** desenvolvido para analisar arquivos de texto e gerar um relatório detalhado com a contagem de caracteres por linha, incluindo um resumo estatístico consolidado.

---

## 🚀 Funcionalidades

- **Execução sob demanda:** Processa o arquivo ativo apenas quando solicitado.
- **Relatório em nova aba:** Não altera nem polui o arquivo original.
- **Resumo estatístico:** Agrupa a quantidade de linhas por tamanho de caractere em ordem crescente.
- **Detalhamento linha a linha:** Enumera cada linha com sua contagem individual de caracteres no formato `L0001 [XX chars]: ...`.

---

## 📦 Instalação

### Via Package Control (Recomendado)
1. Pressione `Ctrl + Shift + P` (Windows/Linux) ou `Cmd + Shift + P` (macOS).
2. Digite `Package Control: Install Package` e pressione **Enter**.
3. Procure por `CountCharLine` e confirme a instalação.

### Instalação Manual
1. No Sublime Text, acesse o menu **Preferences** > **Browse Packages...**.
2. Abra o terminal na pasta aberta e clone o repositório:
```bash
	git clone [https://github.com/andre-fga/count-char-line.git](https://github.com/andre-fga/count-char-line.git)
```
